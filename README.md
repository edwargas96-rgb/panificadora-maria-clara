# Panificadora Maria Clara

Site estático (HTML/CSS/JS) da Panificadora Maria Clara, Capão Raso, Curitiba. Sem build: na Vercel, framework "Other", sem build command, output na raiz.

- Vídeo dos produtos: colocar o arquivo em `video/produtos.mp4`. Enquanto ele não existir, a seção é escondida.
- Pendente: fotos reais de bolos e salgados (cards "Foto em breve") e conferir telefone.
